Privacy Policy

Last updated: August 25, 2026

The short version: OpenSesame does not collect user data. No accounts, no tracking, no analytics, and no personal information are stored by this application or its companion Alexa skill.

On this page Overview Information We Collect Device Data Third-Party Services Data Retention Alexa Skill Permissions Security Children's Privacy Changes to This Policy Contact

Overview

OpenSesame ("the app", "we", "our") is a demonstration smart home platform, delivered as a web dashboard and a companion Alexa skill. This policy explains what information the app does and does not handle when you use it.

Information We Collect

OpenSesame does not require an account and does not collect, store, or process any personal information, including but not limited to:

  • Names, email addresses, or phone numbers
  • Passwords or authentication credentials
  • Location data
  • Voice recordings or transcripts
  • Cookies, analytics identifiers, or advertising identifiers

The app runs in a "demo mode" — every visitor uses the same shared, non-identifying session label, and no sign-in step exists to tie activity to an individual.

Device Data

When you add a device (e.g., a lock or a light) through the dashboard, its name and type are sent to the OpenSesame backend so it can be displayed and controlled. This data:

  • Is used solely to render and operate the demo dashboard
  • Is not linked to any personal identity
  • Is not sold, rented, or shared with advertisers
  • Can be removed at any time using the Delete action in the dashboard

Third-Party Services

OpenSesame does not use analytics, advertising, or tracking services. The app is hosted as a static site and communicates only with its own backend API to read and control demo devices. No data is shared with third parties for marketing or profiling purposes.

Data Retention

Because no personal data is collected, there is no personal data retention period. Demo device entries persist only until they are deleted by a user or reset as part of routine maintenance of the demo environment.

Alexa Skill Permissions

The OpenSesame Alexa skill is for testing and demonstration purposes only. It does not request access to your Amazon account profile, does not store voice transcripts beyond what Amazon requires to process a spoken request, and does not share skill usage data with third parties.

Security

All communication between the dashboard and the backend API uses HTTPS. Since the app does not collect personal data, there is no sensitive personal data at risk in the event of a service issue; demo device data is treated as non-sensitive, disposable test content.

Children's Privacy

OpenSesame is a technical demonstration and is not directed at children. It does not knowingly collect information from anyone, including children under 13.

Changes to This Policy

This policy may be updated as the demo evolves. Changes will be reflected on this page with an updated "Last updated" date above.

Contact

Questions about this policy can be raised via an issue on the OpenSesame GitHub repository.
